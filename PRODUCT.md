# Product

## Register

brand

## Users

Recruteurs (RH, directeurs artistiques) et clients prospects (agences, marques, studios) cherchant un Directeur Créatif / Chef de Projet. Également la communauté créative (pairs, collaborations).

Contexte : navigation sur desktop et mobile, souvent le soir ou le week-end. Veulent évaluer rapidement le niveau de création, la rigueur et la personnalité.

## Product Purpose

Vitrine professionnelle statique — 6 pages + template projet dynamique. Convertir un visiteur en contact (recrutement ou mission freelance). Le design est le produit : l'élégance du site prouve le niveau de création.

## Brand Personality

Luxe sobre, précision, raffinement créatif. Éditorial, affûté, sans esbroufe. L'or est un accent, pas un drapeau.

## Anti-references

- sites Bootstrap / frameworks CSS standardisés
- boutons arrondis (border-radius: 50px)
- couleurs vives hors palette
- box-shadow lourdes, gradients colorés
- cartes identiques avec icône + titre + texte (AI slop)
- numbered section markers (01 / 02 / 03) sur chaque section
- tiny uppercase tracked eyebrow au-dessus de chaque section

## Design Principles

- **Le luxe est dans l'espace** : padding généreux, typographie aérée, silence visuel
- **L'or est un sel, pas un plat** : utilisé en dose infinitésimale, jamais en fond
- **La contrainte libère** : une police display + une police corps, une couleur d'accent, des carrés
- **Le détail prouve l'exigence** : hover animations subtiles, séparateurs fins, transitions letter-spacing
- **La performance est une élégance** : vanilla JS, pas de frameworks, pas de bloat

## Accessibility & Inclusion

- WCAG AA visé (contraste 4.5:1)
- prefers-reduced-motion supporté (scroll-reveal.js désactivé)
- navigation clavier implicite
- loading="lazy" sur les images de grille
